## PhysVis 1.0.0 — 高中物理运动可视化（开源首发）

输入一道物理题（文本或截图），AI 解析建模，精确物理引擎渲染成可交互 2D 动画：实时调参、受力分析、x-t / v-t / a-t 联动图表、分步讲解慢放。纯前端、零后端、AI BYOK。

**内置内容**
- 20 个场景模板：P0 基础运动（匀变速 / 自由落体 / 竖直上抛 / 平抛斜抛 / 匀速圆周 / 弹簧振子 / 单摆）、P1 综合模型（斜面 / 传送带 / 碰撞 / 追及相遇）、P2 高考电磁与综合（带电粒子电场 / 磁场 / 组合场、圆环内壁、竖直圆周绳杆模型、弹簧连接体、板块模型）
- 20 道内置示例题（含与仿真时间对齐的分步讲解），无 Key 离线走通全流程
- 混合物理引擎：解析解 + Velocity Verlet；碰撞动量守恒、绳/杆约束、弹簧对严格守恒
- AI 通道：DeepSeek / OpenAI 兼容 / Anthropic / Gemini / Mock，支持题目截图识图（视觉模型）
- 图片识图、分步讲解（0.35× 慢放）、物体半径实时调节、33 项浏览器验收
